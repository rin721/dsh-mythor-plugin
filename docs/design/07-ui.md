# UI/UX 与关系可视化

## 工作台

侧边栏新增 Mythor 入口，主区域使用 Harness 原有 main slot。工作台内分为项目导航、内容区和详情/审阅区；主题使用 --dsw-alias-*，文字通过本地化字典。继承宿主 React，不装第二份运行时，不依赖内部 UI 组件。

| 页面 | 内容及主要动作 |
| --- | --- |
| 总览 | 项目版本、对象/正文统计、待审阅变化、进行中任务、问题 |
| 世界 | 人物、地点、组织、物品、设定的筛选、详情、编辑和来源 |
| 结构 | 事件、冲突、故事线、人物弧、伏笔、秘密及揭露 |
| 正文 | 章节/场景导航、Markdown 编辑、修订比较、关联对象 |
| 时间线 | 世界时间与叙述次序并列；未知时间独立列示 |
| 关系图 | 同一领域关系的多种过滤投影 |
| 检查 | 按严重性、规则、对象筛选问题并定位 |
| 审阅 | 操作差异、正文、来源、检查、接受或拒绝 |
| 历史/任务 | 提交及逆变更、阶段产物、暂停恢复、授权 |

新项目入口提供从种子开始与导入原文两条路径。未绑定会话时显示绑定操作；打开某项目不会自动改变其他会话。

## 图谱投影

人物关系图、参与事件图、事件地点图、组织结构、因果剧情图、行动路线和故事线交叉图使用同一 entities/relations。行动路线按世界时间连接地点，不伪造地图坐标。故事线交叉通过共享事件/场景表达。

操作：选择类型和时间范围 → 搜索焦点 → 展开一层邻域 → 聚焦/追踪路径 → 查看来源 → 发起编辑。节点移动只保存视图布局，不改变领域。建立/移除关系均产生 ChangeSet。显示总结果与已加载数量，不能把截断图误称为全图。

## 编辑与可访问性

正文使用 CodeMirror；实体表单含公共字段及类型特有属性。保存草稿与接受正式变更分开。输入错误就地显示，冲突保留用户输入并提供比较。导入先预览章节拆分结果，再提取候选事实。

所有图形提供列表对应视图，键盘可聚焦对象，详情有可读名称。颜色之外用图标/文字区分状态。支持深浅主题、窄屏折叠、模态焦点约束、Escape 关闭和加载/空白/失败/离线状态。

## 验证

以上是持续演进的交互设计。0.1.0 的时间线使用排序列表，未知时间排在末尾；图谱按单一时间点过滤，节点拖动尚不持久化布局。检查页提供诊断列表，组合筛选和自动定位仍待扩展；正文修订差异在候选审阅中查看。深色主题切换尚未实测。具体交付与验证范围以 [实施记录](../implementation/status.md) 为准。

以真实安装后的 Harness 页面作为 UI 验证对象。验证导航、主题、编辑、导入、审阅、图谱聚焦、任务取消与恢复，并检查浏览器报错。独立开发 fixture 只用于确定性测试，不代替宿主集成验证。
